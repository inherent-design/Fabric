# UI and HUD

> **Not yet implemented.** Design placeholder for a confirmed game feature.

## Purpose

In-game user interface: health/resource display, function selection, minimap or compass, menus, settings, onboarding prompts.

## Requirements

- Health and resource bars (essence costs per FUNCTION_META_SYSTEM.md)
- Function hotbar or selection interface
- Damage feedback (screen flash, directional indicator)
- Pause menu, settings, keybind configuration
- Onboarding: contextual prompts for first-time function discovery

## Open Design Questions

- HUD density (minimal per AESTHETIC.md vs information-rich)
- Function selection method (hotbar numbers, radial wheel, or combo input)
- Minimap vs compass vs no navigation aid
- UI framework (RmlUI already in engine, or custom immediate-mode)
