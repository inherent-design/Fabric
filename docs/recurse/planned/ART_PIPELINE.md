# Art Pipeline

> **Not yet implemented.** Design placeholder for a confirmed game feature.

## Purpose

Asset creation and integration pipeline for visual content: voxel palettes, material textures, particle effects, UI art, skybox and lighting.

## Requirements

- Material color palette (ORDER=blues/greys, CHAOS=reds/purples, LIFE=greens/browns, DECAY=dark browns/yellows per AESTHETIC.md)
- Particle effects for function casting and NPC transformation
- Skybox or procedural sky
- Lighting model (global illumination approximation or baked)

## Open Design Questions

- Voxel art style: flat color vs textured faces vs palette-indexed
- VFX authoring tool (particle editor, shader graph, or code-driven)
- Target visual density (Mirror's Edge minimalism per DESIGN_DOCUMENT.md)
- Post-processing stack (bloom, color grading, fog)
