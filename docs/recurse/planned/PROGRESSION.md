# Progression System

> **Not yet implemented.** Design placeholder for a confirmed game feature.

## Purpose

Player advancement through function mastery, NPC interaction outcomes, and loop knowledge accumulation. Ties together the function system, NPC transformations, and temporal loop structure.

## Requirements

- Function mastery levels (discovery, proficiency, mastery per FUNCTION_META_SYSTEM.md)
- NPC faction reputation tracking (per TRIBES.md)
- Cross-loop knowledge persistence (what carries between resets)
- Difficulty scaling based on loop count or player skill

## Open Design Questions

- Mastery unlock pace (per-loop vs cumulative)
- Faction relationship complexity (binary friend/foe vs graduated)
- Power curve across loops (player gets stronger or enemies adapt)
- Completion criteria (fixed number of loops, or player-driven ending)
